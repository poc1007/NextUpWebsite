NextUp Support

How can we help?

Send a private support request. An email address is optional, but include one if you would like a reply.

Please include any visible error message. Never send passwords, verification codes, reset links, API keys or access tokens.

Quick help

Passwords: choose Forgot password in NextUp and open the newest reset email on the same device.

Recommendations: update your profile preferences, then try Discover again.

Account deletion: open Profile settings, choose Delete account and confirm.
